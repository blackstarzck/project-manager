# 원본 차이 점검과 보완 우선순위

2026-10-16. 대상은 로그인된 Manyfast 편집기와 이미 확보한 공개 JavaScript 8개다. 원본에서는 탭 전환·메뉴 열람만 수행한다. 생성·재생성·내보내기 요청, 삭제, 사용자 문서의 AI 전송은 하지 않는다. REA Evidence와 정확한 자산 범위는 [REA 기록](rea-analysis.md)을 따른다.

우선순위는 기존 데이터 보존, 기획 작업 흐름의 차이, 반복 조작의 불편, 시각 차이 순서로 정했다. 자동 검수 통과와 원본 동작의 확인 여부를 별도로 기록한다.

플로우의 **생성/재생성**은 원본에서 새 버전을 만들지만 모든 대화형 부분 편집도 항상 새 버전을 만드는지는 확인되지 않았다. 따라서 현재 문서 편집을 별도 선택으로 유지한다. 원본의 낙관적 생성 중 임시 버전 표시와 달리, 로컬 앱은 승인한 결과만 문서가 되는 원칙에 따라 **제안 승인 시점**에 버전을 확정한다. 새 AI 버전에는 새 플로우를 저장하며 와이어프레임은 해당 버전에서 따로 생성한다. 기존 버전의 와이어프레임은 보존한다.

최종 구현·실패 재현·수정·회귀 결과는 [검수 기록](qa-loop.md)에 연결한다. 원본에서 채워진 와이어프레임을 생성하지 않았으므로 픽셀 단위 재현율을 산정하지 않는다.

6단계 기준 전체 회귀 105개와 단위 검사 91개가 통과했다. 7단계에서는 같은 목적지의 유사 메뉴 통합, 없는 공통 영역 추가, 실제 페이지 작업의 Groq 검수를 완료했다. 오른쪽 페이지 목록과 하단 도구 모음 등 공개 화면 자료의 차이도 보완했다. 최신 전체 검수 수치는 [검수 기록](qa-loop.md)을 따른다.

원본의 비공개 서버 정책과 모델 프롬프트는 미확인이다. 임시 버전·실패·취소·부분 승인에 대해서는 [REA 기록](rea-analysis.md)에 원본 근거와 로컬 계약을 각각 확정했다. 같은 입력을 유료 원본에서 생성하여 비교하는 품질·픽셀·모션 검수는 수행하지 않았으며 재현율을 주장하지 않는다. 팀 계정·협업·공개 링크·외부 커넥터는 별도 운영 범위다.
