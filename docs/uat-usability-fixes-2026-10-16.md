사용자가 승인한 예외에 따라 읽기 전용 `GET /api/projects/:id/revisions/:revisionId` 1개를 추가했다. 기존 API 형식과 DB 스키마는 유지한다. 프로젝트 ID와 이력 ID를 함께 조회하고 다른 프로젝트의 이력은 404로 차단한다. 미리보기는 실제 과거 저장 본문을 가져오며 문서·revision·감사 기록을 변경하지 않는다. HTML은 비활성 템플릿에서 평문으로 추출하며 외부 리소스를 로드하거나 실행하지 않는다.

## 검수 loop

1. 기존 UAT 기록과 디자인 기준 확인 → 변경 → 집중 자동 검사 → 빌드 앱 직접 조작 → 독립 검수 순서로 진행했다.
2. 첫 집중 검사에서 PRD 포커스 2건이 실패했다(전체 11건 중 9건 통과). Tiptap 뷰가 준비되기 전에 포커스를 보낸 원인을 수정했다. 취소 가능한 다음 프레임에서 한 번만 포커스하고 사용자가 다른 곳으로 이동했다면 중단한다.
3. 실패했던 동일 테스트 2건을 그대로 재실행해 2/2 통과했다. 검증 문구·조건을 낮추지 않았고 최초 실패 자료도 보존했다.
4. 새 버전 미리보기 5건과 기존 대화상자 접근성·시각 검사 1건이 6/6 통과했다. 시각 기준 이미지를 갱신하지 않았다.

단위·서버 검사는 **117/117 통과**했으며 그중 새 조회 API 검사는 4건이다. 타입 검사와 production build도 통과했다. 최종 전체 E2E는 **154/154 통과(6.4분)**이며 실패·건너뛰기·flaky·재시도 0이다. 기존 143건에 신규 AI 4건·포커스 2건·이력 미리보기 5건을 더했다. 970·1280·1440px의 기존 접근성·시각 비교도 기준 이미지 갱신 없이 통과했다. 검사 전후 소스·설정·테스트 목록 130개 해시가 동일했다. 이 manifest는 해당 경로의 TS/TSX/CSS와 명시한 설정을 대상으로 하며 전체 저장소 파일을 포괄한다는 의미는 아니다.

## 실제 빌드 앱 직접 UAT

1280×720 인앱 브라우저, `127.0.0.1:4334`, 격리 `uat.sqlite`에서 합성 프로젝트 `UAT-개선 확인 · 도서 예약`을 생성했다. 개발 서버나 테스트 코드의 자동 조작으로 이 직접 UAT를 대신하지 않았다. 후보 JS는 `index-CorVSY4P.js`, CSS는 `index-B7jKg5ST.css`다.

시간은 도구 왕복·증거 기록을 포함한 에이전트 수행 시간이며 사람의 속도와 비교하지 않는다. 개별 과제의 시작·종료 원시 시각은 저장하지 않았으며, 중간 점검을 포함한 전체 직접 세션은 약 183초다. 콘솔 오류·경고는 0건이다. 복원 클릭 도구는 CDP 응답 시간 초과를 보고했지만 실제 복원은 완료됐다. 중복 제출하지 않고 문서·새로고침·이력으로 결과를 확인했으며 이 도구 사건을 `uat-results.json`에 보존했다. 확인창 문구·승인은 별도 실제 200% 검수에서 확인했다.

두 직접 실행의 합성 프로젝트는 PRD만 작성했다. 내용이 채워진 기능명세·플로우·와이어프레임의 복원까지 이번 직접 UAT에서 모두 실행했다는 뜻은 아니다. 다른 문서의 보존·복원은 기존 자동 회귀 결과와 구분한다.

AI는 앞선 실제 Groq 응답에서 보관한 목표 사용자·성공 기준 두 항목을 로컬로 재생했다. 직접 UAT 1회, 별도 200% 검수 1회이며 이번 작업의 **외부 Groq 0회·Manyfast 0회**다. 테스트 서버는 외부 fetch를 차단한다. 새 프롬프트에 대한 모델 품질을 다시 검증한 결과로 해석하지 않는다.

## 실제 200% 확대·접근성 검수

별도 에이전트가 격리 Chrome 프로필의 실제 페이지 확대를 200%로 설정했다. 1440×1000 → 720×500, DPR 1 → 2, CSS zoom 1, 브라우저 바깥 크기 동일을 확인했다. 같은 후보 빌드에서 4개 개선 모두 통과했고 주요 조작 13개에 접근 가능했다. 콘솔·페이지 오류는 0건이다.

axe 4개 화면의 확정 위반은 0건이다. AI 검토·버전 미리보기 모달에서 `aria-hidden-focus`가 각 3개 노드에 대해 미판정으로 남아 삭제하거나 제외하지 않았다. 이어서 실제 Tab·Shift+Tab 순환을 각각 10·26단계 확인했다. 포커스가 모달 안에 머물렀고 숨긴 배경·포커스 가드에 머무르지 않았으며 Esc 후 시작 버튼으로 돌아왔다. 이 후속 검사는 추가 재생 없이 진행했으며 문서 전후도 동일했다.

UAT 조작자가 아닌 별도 에이전트가 AX 기록과 실제 이미지 9장을 대조해 4개 개선·직접 과제 3/3 통과 판정에 동의했다. 이 검수자는 버전 미리보기 구현에도 참여했으므로 해당 기능의 구현자와 완전히 독립된 검토라고 표현하지 않는다. 차단할 사용성 문제는 발견하지 못했다. 판단 범위와 한계는 `review-evidence.json`에 남겼다.
