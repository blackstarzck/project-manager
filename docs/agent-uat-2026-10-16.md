# 사용자 관점 에이전트 대행 UAT

> 후속 작업: 아래에서 발견한 사용성 4건을 수정하고 같은 세 과제를 빌드 앱에서 다시 수행해 3/3 통과했다. 추가 Groq·Manyfast 호출은 없으며, 변경 내용·실제 200% 확대·최종 회귀·반영 증거는 [사용성 개선 재검수 보고서](uat-usability-fixes-2026-10-16.md)에 기록한다. 아래 내용은 수정 전 최초 검수 기록으로 보존한다.

2026-10-16 22:13–22:14 KST에 에이전트가 실제 인앱 브라우저에서 프로젝트 생성, 한글 입력, 탭 이동, 새로고침, 일부 승인, 버전 복원을 직접 조작했다. 테스트 코드를 실행해 이 세 과제를 대신 수행하지 않았다. 기능 수용 기준은 **3/3 통과**했으며, 사용성 개선 후보 4개를 별도로 남긴다.

## 실행 환경과 범위

- 3100이 사용하는 `dist`를 그대로 제공하는 임시 서버 `127.0.0.1:4334`, 격리 SQLite `uat.sqlite`를 사용했다.
- 브라우저 기본 창 크기 1280×720에서 진행했다. 이번 과제에서 별도의 확대·접근성 전체 회귀는 반복하지 않았다.
- 합성 프로젝트: `UAT-도서 예약 · 에이전트 대행` (`edd882fd-7e2a-435e-b119-1d162eaf7842`). 운영 프로젝트는 수정하지 않았다.
- AI 검토는 앞선 실제 Groq 응답에서 보존된 독립 PRD 항목 두 개(목표 사용자·성공 기준)를 재사용했다. 기존 수동 작성 항목을 보존하고 이 두 항목을 추가하는 로컬 재생 공급자다. 새 프롬프트에 대한 모델의 생성 품질을 검사한 것으로 표현하지 않는다.
- 모델 선택에는 `qa-replay-groq-recording`을 표시했다. 로컬 재생은 1회로 제한하고 서버의 외부 fetch를 차단했다. 추가 Groq·Manyfast 호출은 각각 **0회**다.
- 측정 시간은 도구 왕복과 증거 기록을 포함한 **에이전트 수행 시간**이다. 사람의 작업 속도나 사용성 점수로 해석하지 않는다.

## 과제 결과

| 과제 | 직접 수행과 관찰 | 결과 | 에이전트 시간 |
|---|---|---|---|
| PRD 작성 | 프로젝트 생성 → 제품 정의·사용자 문제 두 문장 입력 → 입력 직후 기능명세 탭 이동 → PRD 복귀 → 새로고침. 두 문장과 저장 완료 상태 유지 | 통과 | 22초 |
| AI 일부 승인 | 승인 전 PRD 2항목 유지 → 추가 제안 2개 중 목표 사용자만 선택 → `선택 승인 1` 클릭 → 문서 3항목 → 닫기·새로고침·검토 재진입. 성공 기준은 문서에 없고 검토 대기 1개로 유지 | 통과 | 30초 |
| 버전 복원 | 승인 이전 v3의 시각을 기록 → v4 상태에서 v3 복원 → 전체 문서 복원 확인창 승인 → 새로고침. 원래 수동 작성 2항목 복귀, 새 v5 `버전 3 복원` 생성, v4를 포함한 v0–v5 기록 보존 | 통과 | 22초 |

오조작·추가 도움 요청은 각 과제 0회, 브라우저 콘솔 오류·경고 0건이다. 입력 포커스를 위한 추가 클릭은 두 항목에서 각각 1회 발생했다. 새로고침 후 두 문장의 실제 내용은 다음과 같다.

> 이용자가 도서관에 방문하기 전에 원하는 책의 대출 가능 여부를 확인하고 예약한다.
>
> 도서관에 직접 방문한 뒤 원하는 책이 대출 중이라는 사실을 알게 된다.

프로젝트 버전 복원은 PRD만이 아니라 전체 문서 상태를 복원한다. 이번 합성 프로젝트에서 작성한 문서는 PRD이며, 다른 문서가 채워진 복원 경로를 이번 과제로 새로 검수했다는 뜻은 아니다.

## 증거와 판정 범위

증거 폴더: [agent-uat-20261016](../.qa-data/agent-uat-20261016/).

- `results.json`: 과제별 수행 시간, 결과, 관찰, 콘솔 기록.
- `provider-evidence.json`, `server.ts`: 응답 출처, 로컬 재생 1회, 외부 호출 차단.
- `01-prd-reloaded.*`: 수동 작성과 새로고침 결과.
- `04-one-selected.*`, `05-partial-approval.png`, `06-partial-reloaded.*`, `07-remaining-proposal.*`: 선택 1개·부분 반영·미승인 유지.
- `08-before-restore.*`, `09-restored-reloaded.*`, `10-restored-history.*`: 복원 전후 내용과 새 이력.

이는 **에이전트가 사용자 역할로 수행한 수용 검수**다. 실제 사용자의 만족도·학습 난이도·최종 인수 의사까지 대신 측정한 것은 아니다. 향후 직접 사용자 UAT를 진행할 경우 이 결과와 구분해 기록한다.

별도 검수 에이전트가 전체 AX 기록과 선택·승인·이력 화면 이미지를 대조해 **3/3 통과 판정에 동의**했다. `build-identity.json`에서 검증된 배포 후보와 현재 제공 파일 6개의 SHA-256 일치를 확인했다. 검수 후 임시 4334 서버와 생성한 탭을 닫고, 3100 앱과 검수 증거는 보존했다(`cleanup.json`).
