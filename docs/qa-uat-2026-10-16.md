**범위 및 최종 인수 확인**

이번 실행은 실제 Groq 응답의 내용 품질·현재 계정 한도나 원본 서비스와의 픽셀 일치를 검증하지 않았다. 운영 Groq 설정 유무와 모델 상태만 읽기 전용으로 확인했다. 독립 HTML 내보내기는 기존 자체 스타일인 `system-ui`, 15px를 사용한다. 기본 14px 설정은 제목과 보조문구의 개별 크기를 모두 14px로 바꾸는 의미가 아니다.

프로젝트 전환은 앱의 목록 → 열기 경로로 검수했다. 동일 문서에서 주소의 `#project/...`만 바꾸는 탐색은 현재 프로젝트를 자동 전환하지 않으며 새로고침이 필요하다. 이는 정상 앱 내 전환과 구분한 후속 개선 사항이다. 기존 대형 JavaScript 청크에 대한 빌드 경고도 남아 있어 번들 분할·성능 측정은 별도 범위다.

사용자 최종 UAT 승인 상태는 **미수행**이다. 아래 항목은 사용자의 실제 업무로 판단할 최종 확인용이며 자동 검사 통과와 구분한다.

- [ ] 실제 기획 하나를 PRD → 기능명세 → 플로우 → 와이어프레임까지 작성할 수 있다.
- [ ] 주로 쓰는 창 크기에서 글자 크기와 편집·승인 흐름이 적절하다.
- [ ] 필요한 내보내기 결과물이 실제 전달·검토 업무에 적합하다.
- [ ] 실제 Groq 결과를 검토하고 승인하는 사용 경험이 기대에 맞는다.

검수용 브라우저 탭과 임시 서버는 종료하고, 3100 운영 앱에는 최종 빌드를 유지했다. 별도 UAT 데이터와 실패/통과 증거는 `.qa-data/qa-uat-20261016/`에 보존한다.
